# Assistente de Otimização e Manutenção do PC

Script em lote (.bat) para diagnosticar, otimizar e recomendar upgrades de hardware em PCs com Windows 10 e 11. Feito para o mercado brasileiro.

## ✨ Funcionalidades

- **Análise de integridade do Windows**: DISM + SFC
- **Verificação de saúde do SSD**: SMART
- **Análise de eventos críticos** das últimas 24h
- **Verificação de drivers** com problema
- **Otimizações seguras**: plano de energia, serviços, telemetria, Game Mode
- **Detecção automática de hardware**: CPU, RAM, GPU, placa-mãe, disco
- **Questionário de manutenção preventiva**
- **Análise de pasta térmica** com banco de dados de marcas nacionais e internacionais
- **Cruzamento cooler x CPU** baseado em TDP
- **Análise de monitor**: resolução, taxa de atualização, tipo de painel
- **Recomendações de periféricos**: mouse, teclado, headset, mousepad, controle
- **Recomendações de simuladores**: voo, corrida, naval
- **Sugestões de upgrade** baseadas em perfil de jogo e orçamento
- **Relatório final** salvo em `.txt`

## 🚀 Como Usar

1. Baixe o arquivo `assistente_pc.bat`.
2. Clique com o botão direito e selecione **"Executar como administrador"**.
3. Siga as instruções na tela.
4. Ao final, o relatório completo será aberto no Bloco de Notas.

## ⚙️ Requisitos

- Windows 10 (versão 1809 ou superior) ou Windows 11
- PowerShell 5.1 ou superior (já vem por padrão)
- Privilégios de administrador

## ⚠️ Aviso sobre preços

Todos os preços de hardware e periféricos incluídos no script são **estimativas baseadas em pesquisa de mercado** realizada em **Setembro de 2026**. Os valores reais podem variar conforme loja, promoção, região e disponibilidade de estoque.

## 🛡️ Segurança

- ✅ Cria ponto de restauração antes de qualquer alteração
- ✅ Não altera a aparência do Windows
- ✅ Não remove arquivos pessoais
- ✅ Reversível via Restauração do Sistema
- ✅ Roda 100% offline (não envia dados para lugar nenhum)
